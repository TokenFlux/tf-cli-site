# Client Brand Icons

The four `client-*.svg` files come from [Lobe Icons](https://github.com/lobehub/lobe-icons), pinned to commit `4aaf4ee1fb2678a7f989ea570f0f6ce14a9abf75`:

- [Claude Code](https://github.com/lobehub/lobe-icons/blob/4aaf4ee1fb2678a7f989ea570f0f6ce14a9abf75/packages/static-svg/icons/claudecode.svg)
- [Codex](https://github.com/lobehub/lobe-icons/blob/4aaf4ee1fb2678a7f989ea570f0f6ce14a9abf75/packages/static-svg/icons/codex.svg)
- [OpenCode](https://github.com/lobehub/lobe-icons/blob/4aaf4ee1fb2678a7f989ea570f0f6ce14a9abf75/packages/static-svg/icons/opencode.svg)
- [Pi](https://github.com/lobehub/lobe-icons/blob/4aaf4ee1fb2678a7f989ea570f0f6ce14a9abf75/packages/static-svg/icons/pi.svg)

The SVG paths are unmodified. Astro Icon embeds and optimizes them at build time, with no external requests or additional runtime library. The upstream MIT license is retained in `LICENSE.lobe-icons.txt`.

Brand names and marks belong to their respective owners. They identify supported clients, not endorsements or partnerships. Official references: [Claude Code](https://code.claude.com/), [OpenAI brand guidelines](https://openai.com/brand/), [OpenCode brand assets](https://opencode.ai/brand), and [Pi](https://pi.dev/).
